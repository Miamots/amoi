# À moi!

Application de tour de rôle en images pour les enfants : groupes avec photos, séquence verticale, sablier, Time Timer, son à la fin, minuteur seul, sauvegarde à exporter et importer. Elle fonctionne sans Internet.

Les photos des enfants restent seulement sur l'appareil. Elles ne sont jamais envoyées sur GitHub.

## Mettre l'app en ligne avec GitHub Pages

1. Sur github.com, clique **New repository**. Donne-lui un nom, par exemple `a-moi`, et choisis **Public**.
2. Dans le nouveau dépôt, clique **uploading an existing file**.
3. Décompresse le zip sur ton ordinateur. Glisse **le contenu** du dossier (`index.html`, `sw.js`, `manifest.webmanifest`, `README.md`, et les dossiers `img` et `fonts`) dans la page. Clique **Commit changes**.
4. Va dans **Settings → Pages**. Sous **Branch**, choisis `main` et `/ (root)`, puis **Save**.
5. Après une minute ou deux, l'adresse s'affiche en haut de la page, par exemple `https://ton-nom.github.io/a-moi/`.

## Installer sur un téléphone ou une tablette

- **iPhone / iPad (Safari)** : ouvre l'adresse, touche **Partager**, puis **Sur l'écran d'accueil**.
- **Android (Chrome)** : ouvre l'adresse, touche **⋮**, puis **Ajouter à l'écran d'accueil** ou **Installer l'application**.

Ouvre l'app une première fois avec Internet. Ensuite, elle fonctionne hors ligne.

## Mettre à jour l'app

Remplace tous les fichiers dans GitHub par ceux du nouveau zip. Les appareils reçoivent la nouvelle version automatiquement quand ils sont connectés à Internet (la page se recharge toute seule, sauf pendant un tour de rôle). Le numéro de version est affiché dans Réglages → Mise à jour. Les groupes et les photos restent en place.

## Bon à savoir

- Sur iPhone, si l'interrupteur du mode silencieux est activé, le bip peut ne pas sonner.
- Si on efface les données du navigateur, les groupes et les photos sont effacés aussi. Exporte une sauvegarde de temps en temps (Réglages → Exporter une sauvegarde).
